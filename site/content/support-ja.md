# サポート

Plotree のサポートは [GitHub Issue](https://github.com/Htkym/Plotree/issues/new/choose) で受け付けます。

## Issue を作成する前に

- [ユーザーマニュアル](user-manual-ja.html)を確認します。
- Issue 作成時に **Bug report**、**Feature request**、**Support question** を選びます。
- Plotree のバージョンまたはコミット、Windows のバージョン、再現手順を記載します。
- 私的な作品本文、登場人物名、スクリーンショット、`.plotree` ファイルは投稿前に削除します。

## 対応について

Issue は可能な範囲で対応します。再現手順が明確な報告ほど調査しやすくなります。重複した Issue を作成せず、補足は GitHub のリアクションまたはコメントで追加してください。

## Issue を作成する

[サポート用 Issue を作成する](https://github.com/Htkym/Plotree/issues/new/choose)
