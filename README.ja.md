# Plotree

[English](README.md) | [日本語](README.ja.md)

小説・ゲーム創作向けのプロット作成ツールです。フローチャート形式のノードエディタで、選択肢やマルチエンディングを含む物語の流れを視覚的に設計できます。

![分岐ストーリーを設計するPlotreeのキャンバス](site/images/screenshots/01-overview-ja.png)

ノード、選択肢、接続線を使って物語の流れを組み立て、タグ・登場人物・レイアウト・外観を一つのプロジェクトで管理できます。

## インストール

次のどちらかの方法でインストールできます。

- [Microsoft Store](https://apps.microsoft.com/detail/9pfl8jdmmtx6)（推奨）: 証明書の確認と更新が自動で行われます。
- [GitHub Releases](https://github.com/Htkym/Plotree/releases/latest) から直接インストール: `Plotree_<バージョン>_DirectInstaller.zip` をダウンロードしてすべて展開し、`Install-Plotree.bat` を実行します。

GitHub 版は自己署名証明書を使用するため、初回インストール時に管理者の許可が必要です。インストーラーは、同梱された証明書が MSIX バンドルの署名と一致することを確認してから、証明書を Windows の「信頼されたユーザー」ストアへ登録します。GitHub 版は自動更新されないため、新しいリリースごとにインストーラーを実行してください。

## 特徴

- **フローチャート式エディタ** — ノード（シーン・選択肢・エンディング）をキャンバス上に配置し、明示的なハンドルからドラッグして接続。表示範囲外に要素がある場合は縦横のスクロールバーを自動表示
- **複数選択と一括操作** — Shift を押しながら空白部分をドラッグして範囲選択（矩形に触れたノードをすべて選択）、Ctrl / Shift クリックで選択の追加・解除、Ctrl+A で全選択。選択したノードはまとめて移動・ピン解除・削除でき、選択ノードと隣接ノード・接続線は枠線の太さで強調表示されます（ハイコントラストでも判別可能）
- **コピーと貼り付け** — Ctrl+C / Ctrl+V、上部ボタン、右クリックメニューから選択中のノードを複製。コピー対象のノード同士を結ぶ接続と、割り当て済みのタグ・登場人物・グループも維持
- **選択肢・マルチエンディング** — 選択肢ノードから複数の接続を張り、接続線に選択肢ラベルを付与可能
- **ハイブリッド自動レイアウト** — 階層レイアウトによる自動整列（左→右 / 上→下 切替可）。手動配置したノードはピン留めされ、自動整列の対象外に（「すべて再整列」でピン解除も可能）
- **ノード外観のカスタマイズ** — 種類（シーン / 選択肢 / エンディング）ごとに、ヘッダー色・幅・高さ・カード表示（タイトルのみ / タイトル＋本文）と、カードに登場人物を表示するかどうかをプロジェクト単位で設定。ノード個別に上書きすることも可能
- **複数タグ・登場人物・グループ管理** — ツールバーでカラータグと登場人物を選択中のすべてのノードへ一括追加・解除（混在状態も表示）。人物は複数グループに所属でき、人物ごとのグループ所属も確認・編集可能
- **Undo / Redo** — Ctrl+Z / Ctrl+Y またはツールバーから、ノード・接続・タグ・人物・外観・レイアウトの変更を取り消し / やり直し。テキスト入力とドラッグ / リサイズは 1 操作として扱います
- **本文・メモ** — 各ノードにあらすじ本文と執筆メモを記録
- **プロジェクトの保存** — 物語と登場人物の情報を `.plotree` ファイルにまとめて保存
- **PNG / SVG / Markdown / テキストエクスポート** — グラフ全体を透明背景の `.png` / `.svg` に、起点からエンディングまでの全ルートを `.md` / `.txt` に書き出し。テキスト出力では行き止まりや到達不能ノードも警告として出力
- **日本語 / 英語 UI** — 設定メニューからいつでも切替（既定は OS の言語に従う）

## 人物相関図とグループ

「人物相関図」では、人物を配置して関係を線でつなげられます。新しく作った線のラベルは、最初は「関係名」です。線を選択すると「詳細」に関係が表示され、関係名とラベルの色を編集できます。選択中の人物は太い白枠で示され、関係の線はグループ背景に重なっていても選択できます。人物の画像には PNG / JPEG を使え、画像はプロジェクトと一緒に保存されます。

人物は複数のグループに所属できます。所属はプロット画面と人物相関図で共有され、プロット画面で設定したグループも人物相関図の背景に反映されます。グループ分けや背景色を変えても、人物の位置は変わりません。同じグループの人物が近くにいるときは背景が1つにまとまり、離れた人物には個別の背景が表示されます。背景が重なるときは、背景とグループ名が階段状にずれて並び、選択したグループが手前に表示されます。背景を選択すると、「詳細」にグループ名と所属人物が表示され、背景のそばに編集メニューが開きます。背景の表示と非表示は、「グループ分け」の右隣にある「グループの表示」で切り替えられます。

プロット画面の人物管理では、人物一覧の右側にグループ一覧が表示されます。人物の割り当て一覧は、グループごとに展開・折りたたみできます。「詳細」の登場人物は1人ずつ別の行にグループ名付きで表示され、文字を選択してコピーできます。カードに登場人物を表示するかどうかは、タイトル・本文の表示方法とは別に設定でき、種類ごとの既定値とノード個別の設定を選べます。初期状態では表示されません。この設定は PNG / SVG 出力にも反映されます。

## 動作環境

- Windows 10 バージョン 1809 以降 / Windows 11

## 注意事項

- Plotree 1.0.5 で保存した `.plotree` ファイルは、1.0.4 以前のバージョンでは開けません。

## 基本操作

詳しい手順と画面例は、[日本語版ユーザーマニュアル](https://htkym.github.io/Plotree/posts/user-manual-ja.html)を参照してください。

| 操作 | 方法 |
|------|------|
| ノード追加 | ツールバー「ノードを追加」グループの「シーン / 選択肢 / エンディング」ボタン、またはキャンバス右クリック |
| ノード移動 | ノードをドラッグ（移動したノードはピン留めされ自動整列の対象外に）。複数選択中に選択ノードの 1 つをドラッグすると選択したノードがまとめて動きます |
| パン | 空白部分を左ドラッグ。中ボタンドラッグ、または Space を押しながら左ドラッグでも操作可能 |
| 範囲選択 | Shift を押しながら空白部分を左ドラッグ（矩形に触れたノードをすべて選択）。Ctrl+Shift+ドラッグで既存の選択に追加 |
| 選択の追加・解除 | ノードを Ctrl クリック / Shift クリック |
| すべて選択 | Ctrl+A（テキスト入力中を除く） |
| ノード接続 | ノード端のハンドル（丸印）を相手ノードへドラッグ |
| コピー / 貼り付け | Ctrl+C / Ctrl+V、上部のコピー / 貼り付けボタン、または右クリックメニュー。選択ノード同士の接続もコピー |
| 詳細編集 | ノードをクリックで右パネルに表示。ダブルクリックでタイトルにフォーカス（複数選択中は選択数と一括操作を表示） |
| カラータグ | ツールバー「カラータグ」グループでタグを新規作成。チェックで選択中のすべてのノードへ追加、解除で削除（横線は一部のノードだけに付いた混在状態） |
| 登場人物・グループ | ツールバー「登場人物」の「割り当て」で選択中のすべてのノードに人物を追加 / 解除。「人物」「グループ」から人物とグループを作成し、人物を複数グループへ所属させる |
| タグ・人物の確認 | 右パネルに、単一選択・複数選択のどちらでも割り当て済みタグと登場人物の要約を表示 |
| ノード外観 | ツールバーの「外観」ボタン（設定 → ノードの外観…）で種類ごとの既定を設定。個別のノードは右パネル「外観」で上書き |
| 選択肢ラベル | 接続線をクリックして右パネルで入力 |
| 削除 | ノード / 接続を選択して Delete キー、または右クリックメニュー（複数選択時は確認ダイアログの上でまとめて削除） |
| 取り消し / やり直し | Ctrl+Z / Ctrl+Y、またはツールバーの Undo / Redo ボタン。選択やパン / ズームなどの表示操作は履歴に入りません |
| 自動整列 | ツールバーの「自動整列」ボタン（▼から「すべて再整列（ピン解除）」も選択可） |
| レイアウト方向 | ツールバーのコンボボックスで「左から右 / 上から下」を切替 |
| キャンバス操作 | ホイールで縦スクロール、Shift+ホイールで横スクロール。Ctrl+ホイール、Ctrl++ / Ctrl+-、上部ボタン、右クリックメニューでズーム |
| ファイル操作 | Ctrl+N（新規）/ Ctrl+O（開く）/ Ctrl+S（保存）/ Ctrl+Shift+S（名前を付けて保存） |
| エクスポート | ファイル → エクスポート → PNG 画像 (.png) / SVG 画像 (.svg) / Markdown (.md) / テキスト (.txt) |
| 言語切替 | 設定 → 言語 → システム既定 / 日本語 / English（再起動後に反映） |
