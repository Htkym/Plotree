# Plotree

[English](README.md) | [日本語](README.ja.md)

小説・ゲーム創作向けのプロット作成ツールです。フローチャート形式のノードエディタで、選択肢やマルチエンディングを含む物語の流れを視覚的に設計できます。

WinUI 3 (Windows App SDK) 製の Windows デスクトップアプリです。

![分岐ストーリーを設計するPlotreeのキャンバス](docs/images/screenshots/01-overview-ja.png)

ノード、選択肢、接続線を使って物語の流れを組み立て、タグ・登場人物・レイアウト・外観を一つのプロジェクトで管理できます。

## 特徴

- **フローチャート式エディタ** — ノード（シーン・選択肢・エンディング）をキャンバス上に配置し、ドラッグで接続。パン・ズーム対応
- **複数選択と一括操作** — 空白部分の左ドラッグで範囲選択（矩形に触れたノードをすべて選択）、Ctrl / Shift クリックで選択の追加・解除、Ctrl+A で全選択。選択したノードはまとめて移動・ピン解除・削除でき、選択ノードと隣接ノード・接続線は枠線の太さで強調表示されます（ハイコントラストでも判別可能）
- **選択肢・マルチエンディング** — 選択肢ノードから複数の接続を張り、接続線に選択肢ラベルを付与可能
- **ハイブリッド自動レイアウト** — 階層レイアウトによる自動整列（左→右 / 上→下 切替可）。手動配置したノードはピン留めされ、自動整列の対象外に（「すべて再整列」でピン解除も可能）
- **ノード外観のカスタマイズ** — 種類（シーン / 選択肢 / エンディング）ごとにヘッダー色・幅・高さ・カード表示（タイトルのみ / タイトル＋本文）をプロジェクト単位で設定。ノード個別に上書きすることも可能
- **複数タグ・登場人物・グループ管理** — ツールバーでカラータグと登場人物を選択中のすべてのノードへ一括追加・解除（混在状態も表示）。人物は複数グループに所属でき、人物ごとのグループ所属も確認・編集可能
- **Undo / Redo と安全な編集履歴** — Ctrl+Z / Ctrl+Y またはツールバーから、ノード・接続・タグ・人物・外観・レイアウトの変更を取り消し / やり直し。テキスト入力とドラッグ / リサイズは 1 操作として扱います
- **本文・メモ** — 各ノードにあらすじ本文と執筆メモを記録
- **JSON 保存** — `.plotree` ファイル（中身は整形済み JSON）で保存。バージョンフィールド付きで将来のフォーマット移行にも対応
- **PNG / SVG / Markdown / テキストエクスポート** — グラフ全体を透明背景の `.png` / `.svg` に、起点からエンディングまでの全ルートを `.md` / `.txt` に書き出し。テキスト出力では行き止まりや到達不能ノードも警告として出力
- **日本語 / 英語 UI** — 設定メニューからいつでも切替（既定は OS の言語に従う）

## 動作環境

- Windows 10 バージョン 1809 以降 / Windows 11
- ビルドには .NET 10 SDK が必要

## ビルドと実行

```powershell
git clone https://github.com/Htkym/Plotree.git
cd Plotree
dotnet build .\Plotree.slnx -p:Platform=x64
```

実行時は exe を直接起動せず、WinApp CLI の `winapp run`（または WinUI の BuildAndRun ワークフロー）を使用してください。

`.plotree` ファイルのパスを引数に渡すと、そのプロジェクトを開いた状態で起動します。

## 基本操作

詳しい手順と画面例は、[日本語版ユーザーマニュアル](docs/user-manual.ja.md)を参照してください。

| 操作 | 方法 |
|------|------|
| ノード追加 | ツールバー「ノードを追加」グループの「シーン / 選択肢 / エンディング」ボタン、またはキャンバス右クリック |
| ノード移動 | ノードをドラッグ（移動したノードはピン留めされ自動整列の対象外に）。複数選択中に選択ノードの 1 つをドラッグすると選択したノードがまとめて動きます |
| 範囲選択 | 空白部分を左ドラッグ（矩形に触れたノードをすべて選択）。Ctrl / Shift を押しながらドラッグすると既存の選択に追加 |
| 選択の追加・解除 | ノードを Ctrl クリック / Shift クリック |
| すべて選択 | Ctrl+A（テキスト入力中を除く） |
| ノード接続 | ノード端のハンドル（丸印）を相手ノードへドラッグ |
| 詳細編集 | ノードをクリックで右パネルに表示。ダブルクリックでタイトルにフォーカス（複数選択中は選択数と一括操作を表示） |
| カラータグ | ツールバー「カラータグ」グループでタグを新規作成。チェックで選択中のすべてのノードへ追加、解除で削除（横線は一部のノードだけに付いた混在状態） |
| 登場人物・グループ | ツールバー「登場人物」の「割り当て」で選択中のすべてのノードに人物を追加 / 解除。「管理」から人物・グループを作成し、人物を複数グループへ所属させる |
| タグ・人物の確認 | 右パネルに、単一選択・複数選択のどちらでも割り当て済みタグと登場人物の要約を表示 |
| ノード外観 | ツールバーの「外観」ボタン（設定 → ノードの外観…）で種類ごとの既定を設定。個別のノードは右パネル「外観」で上書き |
| 選択肢ラベル | 接続線をクリックして右パネルで入力 |
| 削除 | ノード / 接続を選択して Delete キー、または右クリックメニュー（複数選択時は確認ダイアログの上でまとめて削除） |
| 取り消し / やり直し | Ctrl+Z / Ctrl+Y、またはツールバーの Undo / Redo ボタン。選択やパン / ズームなどの表示操作は履歴に入りません |
| 自動整列 | ツールバーの「自動整列」ボタン（▼から「すべて再整列（ピン解除）」も選択可） |
| レイアウト方向 | ツールバーのコンボボックスで「左から右 / 上から下」を切替 |
| キャンバス操作 | マウス中ボタンのドラッグ、または Space キーを押しながら左ドラッグでパン。Ctrl+ホイールでズーム |
| ファイル操作 | Ctrl+N（新規）/ Ctrl+O（開く）/ Ctrl+S（保存）/ Ctrl+Shift+S（名前を付けて保存） |
| エクスポート | ファイル → エクスポート → PNG 画像 (.png) / SVG 画像 (.svg) / Markdown (.md) / テキスト (.txt) |
| 言語切替 | 設定 → 言語 → システム既定 / 日本語 / English（再起動後に反映） |
