Plotree installation
====================

Choose one of the following installation methods.

1. Microsoft Store (recommended)
   https://apps.microsoft.com/detail/9pfl8jdmmtx6

   The Store manages certificate trust and updates automatically.

2. Direct installation from GitHub
   Extract every file from this ZIP, then run Install-Plotree.bat.

   The GitHub version is signed with a self-signed certificate. The installer
   verifies that the included certificate matches the MSIX bundle, asks for
   administrator approval, and adds that certificate to the Local Computer
   Trusted People store before installing Plotree.

   Updates are not automatic. Download and run the installer for each new
   release.


Plotree のインストール
======================

次のどちらかの方法でインストールしてください。

1. Microsoft Store（推奨）
   https://apps.microsoft.com/detail/9pfl8jdmmtx6

   証明書の確認と更新は Microsoft Store が自動で行います。

2. GitHub から直接インストール
   この ZIP のファイルをすべて展開し、Install-Plotree.bat を実行してください。

   GitHub 版は自己署名証明書を使用します。インストーラーは、同梱された証明書が
   MSIX バンドルの署名と一致することを確認した後、管理者の許可を求めます。
   許可すると、証明書をローカルコンピューターの「信頼されたユーザー」ストアへ
   登録してから Plotree をインストールします。

   自動更新には対応していません。新しいリリースごとにインストーラーを
   ダウンロードして実行してください。
