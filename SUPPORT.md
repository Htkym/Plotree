# Support / サポート

Plotree support is provided through [GitHub Issues](https://github.com/Htkym/Plotree/issues/new/choose).

## Before opening an issue

- Read the [user manuals](README.md#user-manuals).
- Choose **Bug report**, **Feature request**, or **Support question** from the issue form.
- Include the Plotree version or commit, Windows version, and steps that reproduce the problem.
- Remove private story text, character names, screenshots, and `.plotree` files before submitting.

## What to expect

Issues are handled on a best-effort basis. Reports with clear reproduction steps are easier to investigate. Use GitHub reactions or comments to add relevant details rather than opening duplicate issues.

## サポートについて

Plotree のサポートは [GitHub Issue](https://github.com/Htkym/Plotree/issues/new/choose) で受け付けます。

- [ユーザーマニュアル](README.ja.md#ユーザーマニュアル)を確認します。
- Issue 作成時に **Bug report**、**Feature request**、**Support question** を選びます。
- Plotree のバージョンまたはコミット、Windows のバージョン、再現手順を記載します。
- 私的な作品本文、登場人物名、スクリーンショット、`.plotree` ファイルは投稿前に削除します。

Issue は可能な範囲で対応します。再現手順が明確な報告ほど調査しやすくなります。
